# Сканер вилок П1/П2

Веб-приложение для автоматического поиска **двухисходных вилок** (только П1 и П2, без ничьих, фор и тоталов) по четырём БК: **Winline, BetBoom, Fonbet, Liga Stavok**. Сканируются оба рынка: **Live** и **прематч**.

## Алгоритм

1. Парсеры собирают коэффициенты только на П1 и П2 со всех 4 БК.
2. Для каждого матча берутся максимальные кэфы: `К1_max`, `К2_max` (с указанием БК).
3. Вилка: `1/К1_max + 1/К2_max < 1`.
4. Для найденных вилок считается доходность в % и суммы ставок при банке 1 000 / 5 000 / 10 000 ₽ (равный выигрыш при любом исходе).

Пример: `К1_max = 2.30 (BetBoom)`, `К2_max = 1.85 (Winline)` → `1/2.30 + 1/1.85 = 0.9753` → доходность **2.53 %**, при банке 1 000 ₽ ставки **446 ₽ / 554 ₽**.

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Открыть http://localhost:8000

## Режимы работы

| Переменная окружения | Значение | Описание |
|---|---|---|
| `SCANNER_MODE` | `demo` (по умолчанию) | Встроенный симулятор котировок — сайт работает сразу, вилки появляются периодически. Удобно для проверки интерфейса и логики. |
| `SCANNER_MODE` | `live` | Реальный парсинг 4 БК (requests + BeautifulSoup, опционально Selenium). |
| `SCAN_INTERVAL` | `10` | Период обновления коэффициентов, сек. |
| `SOUND_ALERT_PROFIT` | `2.5` | Порог доходности для звукового уведомления, %. |
| `DB_PATH` | `arbs.sqlite3` | Файл SQLite с историей найденных вилок. |

Пример live-запуска:

```bash
SCANNER_MODE=live uvicorn app.main:app --port 8000
```

> **Важно про live-режим.** Сайты БК доступны только с российских IP и активно защищаются от парсинга; вёрстка периодически меняется. Парсер Fonbet работает через публичный JSON-API линии; для Winline / BetBoom / Liga Stavok CSS-селекторы в `app/parsers/*.py` может потребоваться актуализировать под текущую вёрстку. Для динамических страниц раскомментируйте `selenium` в `requirements.txt` (нужен установленный Chrome/Chromium).

## Функционал

- Таблица: тип (LIVE / прематч + время начала), спорт, матч, `К1_max` (с БК), `К2_max` (с БК), доходность %, суммы ставок и прибыль для выбранного банка.
- Переключатель рынков: **Все / Live / Прематч**.
- Фильтр по минимальной доходности (например, только > 2 %).
- Автообновление каждые 10 секунд (Live-режим).
- Звуковое уведомление при появлении новой вилки с доходностью > 2.5 % (порог настраивается, звук можно выключить).
- История всех найденных вилок в SQLite (`GET /api/history`).

## Защита от блокировок

- Ротация User-Agent (5 реальных браузерных UA) на каждый запрос.
- Случайные задержки 2–5 секунд между запросами к одной БК (`REQUEST_DELAY_MIN` / `REQUEST_DELAY_MAX`).
- Ошибка одной БК не роняет цикл: сканер продолжает работать на остальных источниках.

## API

| Метод | Описание |
|---|---|
| `GET /api/arbs?min_profit=2&kind=all` | Текущие вилки с доходностью ≥ 2 % (`kind`: `all` / `live` / `prematch`) |
| `GET /api/history?limit=100` | История найденных вилок из SQLite |

## Структура проекта

```
app/
  main.py          # FastAPI: API + раздача фронтенда
  scanner.py       # фоновый цикл сканирования (каждые 10 с)
  arbitrage.py     # формула вилки и расчёт сумм ставок
  db.py            # SQLite-история
  config.py        # настройки
  models.py        # модели данных
  parsers/
    base.py            # ротация UA, задержки, обработка ошибок
    winline.py         # Winline (HTML + BS4, запасной Selenium)
    betboom.py         # BetBoom (SPA — Selenium, запасной requests)
    fonbet.py          # Fonbet (публичный JSON-API линии)
    ligastavok.py      # Лига Ставок (HTML + BS4, запасной Selenium)
    demo.py            # демо-симулятор рынка
    selenium_helper.py # опциональный JS-рендеринг
static/
  index.html, app.js, style.css  # фронтенд без фреймворков
```

## Дисклеймер

Проект предназначен для образовательных целей. Букмекеры ограничивают счета «вилочников»; проверяйте законодательство вашей юрисдикции и правила БК.
